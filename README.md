# Ecosphere (Shuddi.ai)

Ecosphere is a community-driven platform that encourages individuals and organizations to participate in environmental and social impact initiatives. Users can complete tasks, earn rewards, engage with communities, and contribute to meaningful causes through a gamified experience.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Material UI

### Backend
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- JWT Authentication

### Tools
- Git
- GitHub
- Postman
